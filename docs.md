## Stack notes

- **No JS build step.** Root `package.json` has empty `dependencies` and `yarn.lock` is empty. JavaScript is pinned via `config/importmap.rb` (turbo, stimulus, trix/actiontext, sortablejs) plus vendored pins — no esbuild/webpack/Node toolchain.
- **Lockfile drift (non-app):** `package-lock.json` and `node_modules/` contain `@zxing/library` 0.21.3 (and vendored Stimulus helper packages) left over from an earlier `npm install`; the current `package.json` declares no dependencies, so these are vendored artifacts, not an active build dependency.
- **Tooling-only manifests (not app stack):** `.opencode/package.json` pins `@opencode-ai/plugin` 1.14.33 (opencode config tooling) and `.ruby-lsp/Gemfile` adds `ruby-lsp`/`ruby-lsp-rails` (editor tooling) on top of the root Gemfile.
- **SQLite in dev, test, and prod** — no Postgres/MySQL adapter active (MariaDB migration is scripted but not switched).
- **Minitest, not RSpec** — fixtures in `test/fixtures/*.yml`; system tests via Capybara + Selenium/Chrome.
- **No lint or typecheck tooling** configured.
- **Default locale `:it`** — many UI labels and business terms are Italian.
- **Custom authorization** on top of Devise: `Ability` + `UserAbility` + `UserRole`, with a `godlike` flag that bypasses checks.
- **Grape API** mounted at root (`API::Base`) in addition to Rails `/api/v1` routes.
